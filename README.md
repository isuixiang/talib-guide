# TA-lib使用指南
本书以Python TA-Lib库为核心工具，系统讲解技术指标的计算与可视化方法。通过大量代码示例展示如何高效计算各类技术指标，并结合Matplotlib实现专业水准的金融图表绘制。适合量化交易初学者、金融数据分析师以及有志于构建自有量化系统的开发者阅读。
